# PM 대화형 업무지시 모달 레이아웃 전환 메모 (2026-07-10)

## 이번 변경 목적
- 업무지시서를 폼 입력보다 `Raphael ↔ HermesPM 대화` 중심으로 작성하도록 구조 전환
- 작업 제목과 `반드시 나와야 하는 결과`는 사용자가 직접 폼에 쓰지 않고 PM이 대화를 보고 정리
- 최근 결과물 파일 참조 영역은 모달에서 제거하고 메인 페이지에서만 노출
- 맥북 Claude와 병행 검토 시, 현재 UX/동작 변경점을 빠르게 파악할 수 있도록 기록 남김

## 현재 모달 구조
- 왼쪽: PM 대화 영역
  - 대화 bubble
  - `PM에게 설명하기` 입력창
  - `PM에게 보내기` 버튼
  - PM 체크리스트
- 오른쪽: PM 작성 브리프 요약
  - `작업 제목`
  - `나와야 하는 결과`
  - 세부 옵션(기본 접힘)
  - 저장/흐름 시작 버튼

## 동작 방식
- 사용자는 왼쪽 채팅창에 자연어로 설명
- `/api/pm-brief-assist` 응답이 오면 PM이 초안을 정리
- 정리된 `title`, `objective`는 hidden form field에 저장되고, 오른쪽 요약 패널에 표시
- 제목/결과가 비어 있으면 저장 불가
- 최근 결과물 파일은 메인 페이지의 `최근 산출물`, `최근 흐름`, `결과와 검토`에서만 확인

## 구현 파일
- `operations_dashboard/index.html`
- `operations_dashboard/app.js`
- `operations_dashboard/styles.css`

## 확인 포인트
1. 모달 왼쪽이 실제 대화 중심으로 보이는지
2. 오른쪽에 PM이 정리한 제목/결과가 표시되는지
3. PM과 대화 전에는 저장 시 안내 문구가 뜨는지
4. 결과물 파일 목록이 모달에서 사라지고 메인 페이지에만 남는지
5. 기존 `save -> dispatch` 흐름이 그대로 유지되는지

## 참고
- 현재 stage auto-dispatch 구현은 유지됨
- 최신 대시보드 서버는 별도 재기동 후 확인 필요
